B — Sortable table

All 20 categories as table rows. Columns: Category, Critical, Warning, Info counts (sortable). Greyed rows = not yet audited. Click any row to go to that category's detail page.

Pros

  • Dense — see all 20 at once
  • Sortable by severity count
  • Consistent with AuditHealth accordion data

Cons

  • Less visual than cards
  • Severity not obvious without scanning numbers

C — Flat list with quick-nav arrows

Simple list of all 20 categories, single row per category, no accordion expand. Worst severity badge on the right, arrow to drill in. "Not audited" rows are greyed and not clickable. Sorted: critical first → warning → pass → not audited.

Pros

  • Fastest to scan
  • Sorted by urgency automatically
  • Simplest to build — no new patterns

Cons

  • No detail visible without clicking through

My recommendation is C — flat list sorted by urgency. It's the fastest to scan, the simplest to build, and naturally highlights critical issues first. The card grid (A) looks nicer but adds little value over a well-sorted list.
